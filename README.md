# このリポジトリについて

このリポジトリは、pygameを使って簡単なシューティングゲームの作り方を紹介するものです。

## 画像ファイルについて
imagesフォルダ以下の画像ファイルは、[ドット絵ダウンロードサイト DOTOWN](https://dotown.maeda-design-room.net/)で提供されているものです。

soundsフォルダ以下の音声ファイルは、[魔王魂](https://maou.audio/)で提供されているものです。

いずれも、再配布を目的としたものではなく、いずれも本プロジェクトの一部として含めているものです。  
当リポジトリから画像データもしくは音声データのみを取得して当リポジトリのプロジェクトで利用する以外の目的では使用しないでください。

これらの素材データが必要な場合は、[ドット絵ダウンロードサイト DOTOWN](https://dotown.maeda-design-room.net/)もしくは[魔王魂](https://maou.audio/)にアクセスし利用条件などを確認した上でご利用ください。
